# ============================================================================
#  TFAST Performance -- lean AI defines                    CK3 1.20.x
# ============================================================================
#  A PARTIAL defines override. Only the keys below are declared; everything
#  else keeps vanilla values. CK3 merges defines at the KEY level across
#  files, so this file rides alongside 00_ai.txt without replacing it.
#
#  WHAT THIS DOES: the AI recalculates its plans less often, weighs fewer
#  candidates, and searches fewer spouses/diplomatic options. That is the
#  single largest moddable CPU load in the late game. The trade is real:
#  the AI becomes lazier and a little dumber. This mod is for slow machines
#  and huge campaigns, not for difficulty.
#
#  CONFLICT NOTE: tfast_smarter_ai tunes the SAME keys the other way. Do not
#  expect both to apply - whichever file the game merges last wins per key.
#  This file is named zz_... so it sorts last inside its own load group; if
#  you want the smarter AI instead, disable this mod.
#
#  WHAT THIS DOES NOT DO: it cannot remove the engine cost of thousands of
#  living characters, large wars, or pathfinding. Pair it with
#  tfast_lategame (character population) and the game's graphics settings.
# ============================================================================
