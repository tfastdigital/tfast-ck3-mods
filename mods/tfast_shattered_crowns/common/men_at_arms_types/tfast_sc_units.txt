#  and 00_maa_types.txt (type = existing archetype, stats, counters, costs,
#  can_recruit trigger, illustration).
#
#  DESIGN CONTRACT (per unit: strength / weakness / cap / cost / counter):
#    * Every unit reuses an EXISTING archetype (heavy_infantry, heavy_cavalry,
#      light_cavalry, pikemen, skirmishers), so no new graphical unit type,
#      no new animations, no new art is needed.
#    * Every unit is locked behind `can_recruit = has_character_flag =
#      tfast_sc_hollow_host`, a flag only the Hollow ever receive. No mortal
#      ruler, and not the player's own dynasty, can ever recruit them.
#    * `max` caps every type hard, so a runaway Hollow AI cannot flood the
#      map with them; the Reckoning wave cap in the story cycle caps event
#      reinforcements further.
#    * Illustrations reuse existing vanilla regimenttype art.
#
#  The player's countermeasures are the documented ones: pikes and heavy
#  infantry blunt the knights and hordes, archers bleed the wraiths, and the
#  Great Wall (decisions) blocks scripted raid entry until a gate breach.
# ============================================================================
