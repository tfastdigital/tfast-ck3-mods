# ============================================================================
#  TFAST Shattered Crowns -- the Hollow Tide situation         CK3 1.20.x
# ============================================================================
#  The Hollow threat as a first-class Situations-window entry, exactly the
#  way vanilla models the Christian Church or the Great Steppe. The window
#  shows the current chapter of the crisis for every landed ruler:
#
#    Predatory Peace -> Escalation -> The Great Reckoning
#        -> Aftermath        (the Host withdrew)
#        -> The Long Dark    (the Reckoning was lost)
#               -> The Uprising -> Aftermath (the dark breaks)
#
#  Phases advance on our own catalysts, fired from the crisis scripts:
#    catalyst_tfast_sc_escalation  crisis phase 2 begins
#    catalyst_tfast_sc_reckoning   phase 3 (the Reckoning begins)
#    catalyst_tfast_sc_aftermath   the Reckoning ends un-lost
#    catalyst_tfast_sc_dark        a Reckoning the world lost (phase 6)
#    catalyst_tfast_sc_uprising    the world rises
#    catalyst_tfast_sc_dawnbreak   the Long Dark breaks
#    catalyst_tfast_sc_peace       the Hollow stir again after a recovery
#
#  No custom GUI: the generic window_situation (the one the debug situation
#  uses) and our own DDS icons under gfx/interface/icons/situations/tfast_sc.
#  The situation is unique, never ends, and is started - once - by the
#  director (tfast_sc_director_yearly_effect), which also covers existing
#  saves that predate it.
# ============================================================================
