#  The Hollow Communion is the faith of the Hollow Dynasty. It exists so the

#  Structure verified against game/common/religion/religion_types/00_hellenism.txt
#  (same religion-level doctrine layout, same doctrine keys).
#  No doctrine key below is invented; every one is defined in
#  game/common/religion/doctrine_types/.
# ============================================================================
