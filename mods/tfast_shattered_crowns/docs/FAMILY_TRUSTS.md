# Family trusts

Status: POSTPONED. No trust script is in the mod.

A trust that can pay gold while the founder still has that gold is a duplicate treasury. The safe version is a single reserve variable funded by `remove_short_term_gold` or an equivalent verified debit, spent only through scripted distributions. That requires the same accounting rules as banking.

Nothing in Phase 1 creates a trust, a trustee, a beneficiary, or a charter.
