# Banking system

Status: POSTPONED. No banking script is in the mod.

CK3 gold is a character stock. A bank that also stores that gold has to move the same coins once: out of the depositor, into a recorded reserve, and back out on withdrawal. The installed game has no corporation, no landless bank title, and no native deposit ledger. A playable banking dynasty would be a character with a treasury, which is easy to double-count.

Phase 4, when it is built, has to start as one player house and one AI house, with explicit variables for reserves, deposit liabilities, and outstanding loans, and with every transfer removing gold from one character and adding the same amount to another. That work is not started.

Until then there is no deposit, withdrawal, loan, interest, default, branch, or bank-failure content.
