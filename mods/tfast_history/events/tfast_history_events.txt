#  TFAST History -- flavor events                                CK3 1.20.x

#  Short narrative payoffs for the larger historic decisions. These are only
#  ever fired by the player's own decisions, never by the AI or a pulse, so
#  they cannot appear in a game the player did not ask for.

#    namespace = x   ->   x.0001 = { theme, title, desc, option = { name } }
#  with localization keys x.0001.t, x.0001.desc and x.0001.a

#  `theme` is REQUIRED. A live run logged "Theme missing in event" for both of
#  these before the field was added - see docs/RUNTIME-CHECKING.md.
# ============================================================================
