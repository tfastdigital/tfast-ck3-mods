# ============================================================================
#  TFAST History -- historic reputation traits                   CK3 1.20.x
# ============================================================================
#  Traits that represent a ruler's historical standing or role.
#
#  WHY THIS IS SAFE
#  ----------------
#   * category = fame, exactly how vanilla models standing/reputation traits
#     (verified against game/common/traits/00_traits.txt).
#   * `icon` reuses an EXISTING vanilla texture from
#     gfx/interface/icons/traits/. The mod ships no art, so there is nothing to
#     go missing and nothing to overwrite.
#   * Every stat key below appears in vanilla trait/modifier files, so none are
#     invented.
#   * Additive only. No vanilla file is replaced.
#
#  Traits are granted by the decisions in 00_tfast_historic_decisions.txt.
# ============================================================================
